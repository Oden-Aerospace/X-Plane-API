# Published specifications

Approved feature specifications published from the spec-driven development
workspace. Each `<feature-slug>/spec.md` is a snapshot of the approved
working spec at publication time; implementation plans, task breakdowns, and
discovery notes remain working artifacts in the development workspace and are
not published here.

| Spec | Scope |
| --- | --- |
| [xplane12-adsb-test-harness](xplane12-adsb-test-harness/spec.md) | Telemetry client, normalized state, JSONL recording/playback, local harness, 1090ES groundwork |
| [glass-cockpit](glass-cockpit/spec.md) | G1000-inspired glass primary flight display |
| [instrument-only-routes](instrument-only-routes/spec.md) | Dedicated `/glass` and `/sixpack` display routes |
| [mfd-navigation-map](mfd-navigation-map/spec.md) | Navigation MFD map with configurable aviation data providers |
| [autopilot-api](autopilot-api/spec.md) | AFCS-style autopilot API: button/selector inputs, annunciated state read-back, agent documentation |
